import pandas as pd

csv_text = """id,group,score,updated,email,future_flag

14. MCAR

What we are doing and why

Missing completely at random means the chance of a blank is independent of both observed and missing values. We choose row positions at random.

How to do it

Run step 14 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(42)
full = pd.DataFrame({"group": ["a", "a", "b", "b", "a", "b"],
                     "value": [2, 4, 6, 8, 10, 12]})
incomplete = pd.DataFrame({"x": [1, 2, 3, 4, 5, 6],
                           "group": ["a", "a", "a", "b", "b", "b"],
                           "value": [2, np.nan, 6, 8, np.nan, 12]})

mcar = full["value"].copy().astype(float)
random_rows = rng.choice(len(full), size=2, replace=False)
mcar.iloc[random_rows] = np.nan
print("MCAR:", mcar.tolist())

Look for

Two values are blank after an independent random selection.

19. Model-based fill

What we are doing and why

When another feature predicts the missing column, learn the relationship from observed rows and predict the blanks. In a modelling pipeline, learn this relationship on training rows.

How to do it

Run step 19 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(42)
full = pd.DataFrame({"group": ["a", "a", "b", "b", "a", "b"],
                     "value": [2, 4, 6, 8, 10, 12]})
incomplete = pd.DataFrame({"x": [1, 2, 3, 4, 5, 6],
                           "group": ["a", "a", "a", "b", "b", "b"],
                           "value": [2, np.nan, 6, 8, np.nan, 12]})

imputer = LinearRegression().fit(incomplete.loc[~missing, ["x"]], values[~missing])
predicted = imputer.predict(incomplete.loc[missing, ["x"]])
print("Model fills:", predicted.round(2).tolist())

Look for

The toy relationship is exact. The predictions for the missing entries are 4 and 10.
