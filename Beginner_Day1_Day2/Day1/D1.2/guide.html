D1.2 · Transformations, categories and leakage

What and why. We will change numbers and categories into model inputs and check whether any information comes from the future. This helps make model results trustworthy.

1. Standardisation

What we are doing and why

Subtract the training mean and divide by the training standard deviation. The fitted training values then have mean 0 and standard deviation 1.

How to do it

The standardised values have mean about 0 and population standard deviation 1.

3. Log and Box-Cox

What we are doing and why

Taking a log can compress a right tail. Box-Cox chooses a power from positive training values. For new inputs we would reuse that fitted power.

How to do it

Run step 3 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

import numpy as np
import pandas as pd

train = np.array([1, 2, 4, 8, 32, 128], dtype=float).reshape(-1, 1)

logged = np.log(train.ravel())
powered, power = boxcox(train.ravel())
for name, values in [("Raw", train.ravel()), ("Standard", standard),
                     ("Min-max", minmax), ("Log", logged), ("Box-Cox", powered)]:
    print(name, "skew:", round(skew(values), 2))
print("Fitted Box-Cox power:", round(power, 2))

Look for

The raw, standardised, and min-max skews match. The log and fitted Box-Cox reduce the skew in this sample.

11. Target encoding with cross-fitting

What we are doing and why

A simple target encoding uses a category's average target. If each ID occurs once, doing that on the same rows copies their answers. Cross-fitting uses other training rows to encode each training fold.

How to do it

Run step 11 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

import numpy as np
import pandas as pd
from sklearn.preprocessing import OneHotEncoder, OrdinalEncoder, TargetEncoder

colors = [["red"], ["red"], ["blue"], ["blue"], ["green"], ["yellow"]]
sizes = [["small"], ["medium"], ["large"]]
ids = np.array([["a"], ["b"], ["c"], ["d"], ["e"], ["f"], ["g"], ["h"]])
target = np.array([0., 1., 0., 1., 1., 0., 1., 0.])

examples = pd.DataFrame({"id": ids.ravel(), "target": target})
naive = examples.groupby("id")["target"].transform("mean")
encoder = TargetEncoder(target_type="continuous", smooth=0.0, cv=2,
                        random_state=0)
cross_fitted = encoder.fit_transform(ids, target).ravel()
print("Naive:", naive.tolist())
print("Cross-fitted:", cross_fitted.tolist())
print("Unseen ID:", encoder.transform([["new"]]).ravel().tolist())

Look for

The naive ID encoding repeats the target. Cross-fitted singleton IDs get the other fold's mean, and an unseen ID at inference gets the full training mean.

14. Target leakage

What we are doing and why

This feature is a copy of the label produced after the outcome. A model gets a perfect score because the answer is in the input.

How to do it

Run step 14 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

import numpy as np
import pandas as pd
from sklearn.metrics import roc_auc_score
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.tree import DecisionTreeClassifier

train = pd.DataFrame({"input": [0, 0, 1, 1, 0, 0, 1, 1],
                      "label": [0, 0, 1, 1, 0, 1, 0, 1]})
test = pd.DataFrame({"input": [0, 0, 0, 1, 1, 1, 1, 0],
                     "label": [0, 0, 0, 1, 1, 0, 1, 1]})

train["outcome_copy"] = train["label"]
test["outcome_copy"] = test["label"]
for names in [["input"], ["input", "outcome_copy"]]:
    model = DecisionTreeClassifier(max_depth=1, random_state=0).fit(train[names], train["label"])
    score = roc_auc_score(test["label"], model.predict_proba(test[names])[:, 1])
    print(names, "test AUC:", round(score, 2))

Look for

The model with the copied outcome gets AUC 1.00. The available-only input gets 0.75.

16. Temporal leakage

What we are doing and why

When the model will predict future rows, test on later rows. A shuffled split can train on dates after the ones in the test set.

How to do it

Run step 16 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

import numpy as np
import pandas as pd
from sklearn.metrics import roc_auc_score
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.tree import DecisionTreeClassifier

train = pd.DataFrame({"input": [0, 0, 1, 1, 0, 0, 1, 1],
                      "label": [0, 0, 1, 1, 0, 1, 0, 1]})
test = pd.DataFrame({"input": [0, 0, 0, 1, 1, 1, 1, 0],
                     "label": [0, 0, 0, 1, 1, 0, 1, 1]})

time = np.arange(1, 11)
random_train, random_test = train_test_split(time, test_size=3, random_state=0)
ordered_train, ordered_test = time[:-3], time[-3:]
print("Shuffled train:", sorted(random_train), "test:", sorted(random_test))
print("Ordered train max:", ordered_train.max(), "test min:", ordered_test.min())

Look for

The shuffled training set includes time points after some test points. In the ordered split, the latest training point is 7 and the earliest test point is 8.
