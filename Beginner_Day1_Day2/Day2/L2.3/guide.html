2. Gradient descent updates

What we are doing and why

A learning rate controls how much the weight changes each step.

How to do it

Run step 2 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

weight = 0.0
for number in range(3):
    gradient = 2 * (weight - 3)
    weight = weight - 0.25 * gradient
    print('Step', number + 1, ':', round(weight,2))

Look for

The value moves toward 3. Epochs count passes through training data and batch size counts examples per update.

3. Baseline and regularised model

What we are doing and why

A baseline gives a simple reference for a learned line.

How to do it

from sklearn.linear_model import Ridge
x = [[1],[2],[3],[4]]
y = [2,4,6,8]
model = Ridge(alpha=1).fit(x,y)
print('Mean baseline:', np.mean(y))
print('Ridge prediction:', round(model.predict([[5]])[0],2))

4. Search for a setting

What we are doing and why

We compare several candidate values of alpha with cross-validation.

How to do it

Run step 4 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

from sklearn.linear_model import Ridge
from sklearn.model_selection import GridSearchCV
x = np.arange(1,9).reshape(-1,1)
y = np.arange(1,9)*2
search = GridSearchCV(Ridge(), {'alpha':[0.1,1.0,10.0]}, cv=2)
search.fit(x,y)
print('Chosen setting:', search.best_params_)

Look for

The grid checks three choices. Random search samples choices; halving spends more work on promising choices.

5. Nested cross-validation

What we are doing and why

An outer split provides a check while an inner process chooses settings.

How to do it

Run step 5 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

from sklearn.model_selection import KFold
outer = KFold(n_splits=2)
for train, test in outer.split(np.arange(6)):
    print('Inner selection uses:', train, 'Outer check uses:', test)

Look for

Each outer test group stays outside that round's selection.

6. Error and selection bias

What we are doing and why

How to do it

check = pd.DataFrame({'group':['A','A','B'], 'actual':[10,20,30], 'predicted':[12,19,25]})
check['error'] = (check['actual'] - check['predicted']).abs()
print(check.groupby('group')['error'].mean())

Look for

Group errors can differ. If a group is absent, we cannot measure its error here.
