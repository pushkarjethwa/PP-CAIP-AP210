2. Split and calculate a baseline

What we are doing and why

We use earlier rows to train and keep the last row for checking.

How to do it

3. Simple linear regression

What we are doing and why

We fit a line and read its slope and intercept.

How to do it

Run step 3 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

from sklearn.linear_model import LinearRegression
x = [[1],[2],[3],[4]]
y = [12,19,31,39]
model = LinearRegression().fit(x,y)
print('Slope:', round(model.coef_[0],2), 'Intercept:', round(model.intercept_,2))
print('Prediction:', round(model.predict([[5]])[0],2))

Look for

The slope says how much the prediction changes when size increases by one.

4. Multiple inputs and a log target

What we are doing and why

We use two columns and show how a log compresses positive values.

How to do it

Run step 4 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

from sklearn.linear_model import LinearRegression
x = [[1,0],[2,1],[3,0],[4,1]]
price = np.array([12,22,30,40])
model = LinearRegression().fit(x,np.log(price))
print('Predicted value:', round(float(np.exp(model.predict([[5,1]])[0])),2))

Look for

The model learns on log values and exp converts the prediction back.

5. Ridge and Lasso

What we are doing and why

Regularisation controls coefficient size. We compare two methods using the same examples.

How to do it

Run step 5 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

from sklearn.linear_model import Ridge, Lasso
x = [[1],[2],[3],[4]]
y = [12,19,31,39]
for model in [Ridge(alpha=1), Lasso(alpha=1)]:
    model.fit(x,y)
    print(type(model).__name__, 'slope:', round(model.coef_[0],2))

Look for

Different methods can produce different slopes. Alpha is a setting.
