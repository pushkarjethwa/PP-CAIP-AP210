2. Trend and repeated positions

What we are doing and why

A rolling mean shows local level. Grouping by position can reveal a repeating cycle.

How to do it

Run step 2 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

series = pd.Series([10,12,11,13,12,14,13,15])
print('Rolling mean:', series.rolling(3).mean().round(1).tolist())
print('Position averages:', series.groupby(series.index % 2).mean().tolist())

Look for

The first two rolling values are missing because three observations are needed.

3. Autocorrelation

What we are doing and why

We compare the series with its previous value.

How to do it

print('Lag 1 correlation:', round(series.autocorr(lag=1),2))

Look for

The number describes the relationship with a one-step shift.

4. Lag and rolling average without leakage

What we are doing and why

We shift first so a feature only uses earlier values.

How to do it

Run step 4 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

series = pd.Series([10,12,11,13,12])
table = pd.DataFrame({'value': series})
table['lag1'] = series.shift(1)
table['past_mean'] = series.shift(1).rolling(2).mean()
print(table)

Look for

At the fourth row the previous-two mean is 11.5.

5. Ordered splits

What we are doing and why

Each training set ends before its test set begins.

How to do it
