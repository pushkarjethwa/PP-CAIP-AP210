2. Underfitting and overfitting

What we are doing and why

We compare polynomial curves of different complexity using the same points and separate checks.

How to do it

Run step 2 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
x = np.array([0,1,2,3,4]).reshape(-1,1)
y = np.array([0,1,4,9,16])
for degree in [1,2,4]:
    model = make_pipeline(PolynomialFeatures(degree), LinearRegression())
    model.fit(x,y)
    print('Degree', degree, 'prediction for 5:', round(model.predict([[5]])[0],2))

Look for

The models produce different predictions. Complexity needs checking on held-out data.

3. Learning with more examples

What we are doing and why

We train on two different training sizes and compare their predictions.

How to do it

from sklearn.linear_model import LinearRegression
x = np.array([1,2,3,4]).reshape(-1,1)
y = np.array([2,4,6,8])
for count in [2,4]:
    model = LinearRegression().fit(x[:count], y[:count])

Look for

4. Cross-validation and hyperparameters

What we are doing and why

We change a tree's maximum depth and evaluate each setting across several held-out folds.

How to do it

Run step 4 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

from sklearn.model_selection import cross_val_score
from sklearn.tree import DecisionTreeRegressor
x = np.arange(12).reshape(-1,1)
y = np.arange(12)
for depth in [1,2]:
    model = DecisionTreeRegressor(max_depth=depth, random_state=0)
    scores = cross_val_score(model,x,y,cv=3,scoring='neg_mean_absolute_error')
    print('Depth:', depth, 'mean error:', round(-scores.mean(),2))

Look for

Depth is a setting chosen before fitting. Each score uses a different hold-out fold.

5. Gradient descent and learning rate

What we are doing and why

We update a number in the direction that reduces a simple loss.

How to do it

Run step 5 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

weight = 0.0
for step_number in range(4):
    gradient = 2 * (weight - 3)
    weight = weight - 0.25 * gradient
    print('Step', step_number + 1, 'weight', round(weight,2))

Look for

The weight moves towards 3. A much larger learning rate can overshoot.
