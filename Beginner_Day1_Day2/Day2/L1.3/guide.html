L1.3 · Transaction features

What and why. We will turn several event rows into one row per item, then check what the new values mean. This makes event data easier to use in a model.

1. Load and compare memory

What we are doing and why

Categories can reduce memory when text values repeat.

How to do it

Run step 1 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

events = pd.DataFrame({'id': ['a','a','b','b'], 'type': ['x','x','y','y'], 'amount': [10,20,30,40]})
print(events)
print('Text bytes:', events['type'].memory_usage(deep=True))
print('Category bytes:', events['type'].astype('category').memory_usage(deep=True))

Look for

The same information can use different amounts of memory.

3. Spend mix and trend

What we are doing and why

4. Join and handle no activity

What we are doing and why

An item with no events needs a flag; a missing average is not a measured zero.

How to do it

Run step 4 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

items = pd.DataFrame({'id': ['a','b','c']})
totals = pd.DataFrame({'id': ['a','b'], 'total': [30,40]})
joined = items.merge(totals, on='id', how='left')
joined['has_activity'] = joined['total'].notna()
joined['total'] = joined['total'].fillna(0)
print(joined)

Look for

C has no activity and its total is filled with zero.

5. Compare a feature with random noise

What we are doing and why

We compare how much a signal and random values relate to a target.

How to do it

Run step 5 in the solution after running Setup. In VS Code use the Run Cell link above the matching # %% heading, or run the whole solution from a terminal. To practise, run the starter and change one value where it is safe to do so. Run the example again and explain what changed.

rng = np.random.default_rng(2)
target = pd.Series([1,2,3,4,5,6])
signal = pd.Series([1,2,3,4,5,6])
noise = pd.Series(rng.normal(size=6))
print('Signal correlation:', signal.corr(target))
print('Noise correlation:', round(noise.corr(target), 2))

Look for

The signal is perfectly related. A random feature can still correlate by chance.
