Trainer overview · Days 1 and 2

Start with the system setup guide. Use the demo guide to teach and the lab guide for practice.

At each step explain what learners will see, run the code and discuss the output. The starter is already runnable. Learners can change an input value, run the step again and explain the change. Run Setup first.

The notebook versions use the same examples. Open one in VS Code, select the beginner kernel and run cells in order with Shift+Enter.

These are small teaching examples. They cover the section topics in the original activities but do not reproduce all methods or produce the original checkpoints. Some advanced methods are introduced by a simplified illustration and a plain-English explanation in the associated step. Later full-course labs require the original checkpoint files.

L1.3 is scheduled on Day 2. Learners may need more time than the original agenda allows when working through all steps.
