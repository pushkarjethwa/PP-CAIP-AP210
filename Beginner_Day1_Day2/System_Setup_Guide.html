System setup guide · Windows and macOS

This guide prepares Windows or macOS to run the beginner Day 1 and Day 2 notebooks in VS Code. Complete the steps for your operating system, then follow the shared steps.

What to install

  • Python 3.12 runs the code.
  • Visual Studio Code (VS Code) opens the notebooks.
  • The Microsoft Python and Jupyter VS Code extensions add Python and notebook controls.
  • A local virtual environment keeps this pack's Python packages together.

Have internet access and the extracted course folder available. Use the folder containing Beginner_Day1_Day2. If you received a ZIP, extract it first with File Explorer or Finder.

The course requirements specify Python 3.10–3.12. The Python 3.12.10 release page provides installer files for both operating systems. Python 3.12.10 is an older installer release, so follow your organisation's software policy when choosing a maintained installation.

Python 3.12.10 downloads · VS Code downloads

Windows · Install Python

  1. Open the Python 3.12.10 download page above. Scroll to Files. For most Intel or AMD Windows computers, choose Windows installer (64-bit). For Windows on ARM, choose the ARM64 installer appropriate for the device.
  2. Open the downloaded installer. If offered, check Add python.exe to PATH, then select Install Now. Follow the prompts and select Close.
  3. Open a new Windows PowerShell window from the Start menu. Run the command below. You should see a version beginning with Python 3.12.
py -3.12 --version

If the launcher is unavailable, try python --version. If this gives a different version, use the installed Python 3.12 interpreter's full path or ask the trainer for help.

Windows · Install VS Code

  1. Open the VS Code downloads page and choose Windows User Installer for your computer architecture.
  2. Run the downloaded installer. Accept the licence and continue through the prompts. Launch VS Code when installation finishes.

Official Windows installation instructions

macOS · Install Python

  1. Open the Python 3.12.10 page above, scroll to Files, and download macOS 64-bit universal2 installer.
  2. Open the downloaded .pkg and follow the installation prompts. Enter your Mac password if requested.
  3. Open a new Terminal from Applications → Utilities. Run this command. The result should begin with Python 3.12.
python3.12 --version

If the command is not found, close and reopen Terminal, then try again.

macOS · Install VS Code

  1. Open the VS Code downloads page and download the macOS Universal build.
  2. Open the downloaded file. If it is a disk image, drag Visual Studio Code into Applications. If it is a ZIP, open it and move the extracted application into Applications.
  3. Open VS Code from Applications and accept the macOS prompt to open the downloaded application if displayed.

Official macOS installation instructions

Both systems · Install extensions

  1. Open VS Code. Select the Extensions icon on the left, or choose View → Extensions.
  2. Search for Python. Select the extension published by Microsoft and choose Install.
  3. Search for Jupyter. Select the extension published by Microsoft and choose Install. Wait until both installations finish.

Python extension instructions · Notebook instructions

Both systems · Open the course folder

  1. In VS Code choose File → Open Folder.
  2. Select the extracted course root, the folder that contains Beginner_Day1_Day2, Day1, and Day2. Choose Select Folder or Open.
  3. If VS Code asks whether you trust the folder, read the prompt and select the appropriate option for your course materials.
  4. Choose Terminal → New Terminal. The terminal normally starts in the opened folder. If you have several folders open, select the course root for the terminal.

Windows · Create and install the beginner environment

Check in the course folder for an existing .beginner-venv first. If one exists, consult the trainer before reusing it. Enter each command separately in the VS Code terminal and press Enter. Wait for each command to complete before entering the next one. These commands use the environment's Python directly, so activation and PowerShell execution-policy changes are unnecessary.

py -3.12 -m venv .beginner-venv
.\.beginner-venv\Scripts\python.exe -m pip install --upgrade pip
.\.beginner-venv\Scripts\python.exe -m pip install numpy pandas scipy pyarrow scikit-learn matplotlib ipykernel
.\.beginner-venv\Scripts\python.exe -c "import numpy, pandas, scipy, pyarrow, sklearn, matplotlib, ipykernel; print('Beginner environment ready')"

Wait for Beginner environment ready.

macOS · Create and install the beginner environment

Check in the course folder for an existing .beginner-venv first. In Finder, use Command + Shift + Period to show hidden files. If the folder exists, consult the trainer before reusing it. Enter each command separately in the VS Code terminal. Wait for each to complete.

python3.12 -m venv .beginner-venv
./.beginner-venv/bin/python -m pip install --upgrade pip
./.beginner-venv/bin/python -m pip install numpy pandas scipy pyarrow scikit-learn matplotlib ipykernel
./.beginner-venv/bin/python -c "import numpy, pandas, scipy, pyarrow, sklearn, matplotlib, ipykernel; print('Beginner environment ready')"

Wait for Beginner environment ready.

Both systems · Select the notebook kernel and test

  1. In Explorer, open Beginner_Day1_Day2 → Day1 → Demo_D1.1.ipynb.
  2. Select Select Kernel at the top right. Choose Python Environments, then the interpreter in .beginner-venv. If it is absent, refresh the environment list or use the option to enter an interpreter path. On Windows the path ends in .beginner-venv\Scripts\python.exe. On macOS it ends in .beginner-venv/bin/python.
  3. Click the first code cell and press Shift + Enter. A small table with columns item and value should appear.
  4. Run the remaining cells in order. A kernel is the Python process that runs the notebook. Select this same environment in each notebook when asked.

Help with common problems

  • Python command not found. Open a new terminal. Check that Python 3.12 installed successfully, then rerun the version check for your operating system.
  • Package installation fails. Check the internet connection and the full error message. Run the install command again using the environment's Python path shown above. Managed computers may need help from IT.
  • Kernel or ipykernel missing. Verify both extensions are installed. Run the package installation command again, then select the .beginner-venv interpreter in the notebook kernel picker.
  • ModuleNotFoundError. Select the correct kernel and rerun the import check. Installing a package into one interpreter does not install it into another.
  • NameError or a result is missing. A preceding cell may not have run. Restart the notebook kernel and run every cell from the top.
  • File or notebook not visible. Check that the ZIP is extracted and that VS Code opened the course root rather than the ZIP file.
