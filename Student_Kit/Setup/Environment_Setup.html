Environment setup

Get ready in 15 minutes

Use a local Python 3.12 virtual environment (recommended) or Google Colab.

Option A — local (Windows / macOS / Linux)

  1. Install Python 3.12 from python.org. TensorFlow does not support 3.13 or newer yet.
  2. Open a terminal in the course folder and run:
py -3.12 -m venv .venv          # macOS/Linux: python3.12 -m venv .venv
.venv\Scripts\activate           # macOS/Linux: source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r 00_Course_Design/requirements.txt

If data/ is empty, generate the datasets (≈ 90 s, ≈ 230 MB):

python data/generate_data.py            # full size
python data/generate_data.py --scale 0.3   # low-spec laptop

Start Jupyter from the course root so every notebook can find data/ and checkpoints/:

jupyter lab

Option B — Google Colab

  1. Upload the whole course folder to Google Drive.
  2. In each notebook, run first: from google.colab import drive; drive.mount('/content/drive') then %cd /content/drive/MyDrive/<course folder>/DayN/Labs/<lab folder>.
  3. The setup cell then finds data/ and checkpoints/ automatically. Day 5 needs !pip install mlflow fastapi httpx.
