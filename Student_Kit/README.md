# CAIP AIP-210 · Project MIZAN — Student Kit

**Open `index.html` in a browser to start.**

| Folder | Contents |
|---|---|
| `Setup/` | Environment setup guide and `requirements.txt` |
| `Assessments/` | Pre-assessment (take it before Day 1) |
| `StudyGuides/` | One study guide per day |
| `DayN/Labs/<id>/` | Lab guide (HTML), Level 1 and ★ Level 2 notebooks |
| `DayN/Exam_Practice/` | 12 scenario questions with explanations |
| `data/` | 10 synthetic datasets + data dictionary |
| `checkpoints/` | Hand-off files, so you can start any lab |

Level 3 solutions and the post-assessment are not in this kit. Your trainer shares them as
`DayN_Release.zip` at the end of each day. Extract each release into this folder.

All data is synthetic. Horizon Gulf Bank and Project MIZAN are fictional.
