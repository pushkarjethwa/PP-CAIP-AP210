1. Support Vector Machines: Hyperplanes, Margins and Support Vectors

What & Why

An SVM classifier finds the hyperplane (a line in 2D, a plane in 3D) that separates two classes with the widest possible margin, meaning the gap between the boundary and the nearest points of each class. Those nearest points are the support vectors: only they define the boundary; other points could move without changing it.

  • C controls the trade-off between a wide margin and training errors. Small C = softer margin, tolerates mistakes (more regularisation, can underfit). Large C = fewer mistakes allowed (can overfit).
  • Feature scaling is essential, because margins are distance-based.
  • SVMs train slowly as rows grow (training cost grows faster than linearly), so on millions of rows use a sample, or LinearSVC / SGDClassifier.
  • SVC does not output probabilities by default; use decision_function scores, or probability=True (slower, uses internal cross-validation).
AnalogyBuilding a road between two neighbourhoods as far from both as possible. Only the houses closest to the road (support vectors) decide where it can go.
Finance example

Separating defaulting from non-defaulting small-business borrowers using a few well-scaled financial ratios, where a clean boundary with a healthy margin is preferred to a boundary that hugs the training points.

A linear SVM in a scaling pipeline (on a stratified sample)
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.metrics import classification_report

loans = pd.read_csv("data/loan_applications.csv")
f = ["loan_amount_aed", "tenure_months", "monthly_salary_aed", "aecb_score",
     "debt_burden_ratio", "num_prior_delinquencies_24m"]
X, y = loans[f].fillna(loans[f].median()), loans["default_12m"]

# SVMs scale poorly with rows -> use a stratified subsample
X, _, y, _ = train_test_split(X, y, train_size=15_000, stratify=y, random_state=42)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)

svm = make_pipeline(StandardScaler(), SVC(kernel="linear", C=1.0, class_weight="balanced"))
svm.fit(X_tr, y_tr)
print(classification_report(y_te, svm.predict(X_te)))
print("support vectors per class:", svm[-1].n_support_)

2. Kernels, gamma and Support Vector Regression

What & Why

When classes are not linearly separable, the kernel trick lets an SVM behave as if the data were mapped to a higher-dimensional space where a flat boundary works, without computing that mapping explicitly. Common kernels: linear, poly, rbf (radial basis function, the usual default) and sigmoid.

  • gamma (RBF/poly/sigmoid): how far one training point's influence reaches. Large gamma = very local, wiggly boundary (overfit). Small gamma = smooth boundary (underfit). In scikit-learn gamma="scale" is the default.
  • Tune C and gamma together, typically on a log-scale grid.

Support Vector Regression (SVR) fits a function within a tube of width epsilon: errors smaller than epsilon cost nothing; only points outside the tube become support vectors. C and kernel work as in classification.

AnalogyKernels are like looking at tangled strings from above (2D) versus lifting them into the air (3D): from the new viewpoint you can slide a sheet of paper between them.
Finance example

Estimating loss given default (the fraction of an exposure lost when a borrower defaults) from collateral and loan features with SVR, where small prediction errors inside the tube are tolerated.

RBF SVM tuned over C and gamma; SVR for a continuous target

3. The Artificial Neuron: Weights, Bias and Activation Functions

What & Why

An artificial neuron computes z = w1*x1 + w2*x2 + ... + b (inputs times weights, plus bias) and then applies a non-linear activation function: a = f(z). Without activation functions, any stack of layers collapses to one linear model.

ActivationOutput rangeTypical use
ReLU: max(0, z)0 to infinityDefault for hidden layers; cheap, reduces vanishing gradients.
Sigmoid: 1/(1+e^-z)0 to 1Output layer for binary probability.
Tanh-1 to 1Zero-centred; used inside recurrent units.
Softmax0 to 1, sums to 1Output layer for multi-class probabilities.
AnalogyA neuron is a committee member who weighs each piece of evidence (weights), starts with a built-in leaning (bias) and only speaks up strongly if the total passes a certain level (activation).
Finance example

One neuron fed with a transaction's amount, distance from home and merchant risk can already output a "fraud probability" (a sigmoid neuron is exactly logistic regression); the power comes from stacking many of them.

A single sigmoid neuron in NumPy
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

x = np.array([0.8, 1.5, 0.3])        # scaled inputs: amount, distance, merchant risk
w = np.array([0.9, 0.4, 1.2])        # weights (learned in training)
b = -1.0                             # bias

z = np.dot(w, x) + b                 # weighted sum
print("fraud probability:", sigmoid(z))

4. Training a Neural Network: Layers, Loss, Backpropagation, Epochs, Batches and the MLP

What & Why

A Multi-Layer Perceptron (MLP) has an input layer, one or more hidden layers and an output layer, fully connected. Training is a loop:

  1. Forward propagation: push a batch of inputs through the layers to get predictions.
  2. Loss function: measure error (binary cross-entropy for yes/no, categorical cross-entropy for classes, MSE for numbers).
  3. Backpropagation: apply the chain rule to compute how much each weight contributed to the loss (the gradients).
  4. Optimiser (SGD, Adam): update weights by a step of size learning rate opposite the gradient.
  • Epoch: one full pass over the training data. Batch size: samples per weight update. Learning rate: step size.
  • Control overfitting with early stopping (stop when validation loss stops improving), dropout and regularisation.
  • Scale inputs; neural networks are scale-sensitive.
AnalogyA chef adjusting a recipe: taste (forward pass), measure how far off it is (loss), work out which ingredient caused it (backprop), adjust each a little (learning rate), repeat over many dinners (epochs).
Finance example

A feed-forward network predicts default risk from many scaled application features. It can capture interactions between features, but on plain tables a gradient-boosted or forest model is often just as good and easier to explain.

An MLP in Keras (TensorFlow) with early stopping
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

# X_tr_s, X_val_s: scaled feature arrays; y_tr, y_val: 0/1 labels (prepare as in Day 1)
n_features = X_tr_s.shape[1]

model = keras.Sequential([
    layers.Input(shape=(n_features,)),
    layers.Dense(32, activation="relu"),
    layers.Dropout(0.2),
    layers.Dense(16, activation="relu"),
    layers.Dense(1, activation="sigmoid"),          # probability of the positive class
])
model.compile(optimizer=keras.optimizers.Adam(learning_rate=1e-3),
              loss="binary_crossentropy",
              metrics=[keras.metrics.AUC(name="auc")])

early = keras.callbacks.EarlyStopping(monitor="val_loss", patience=5, restore_best_weights=True)
history = model.fit(X_tr_s, y_tr, validation_data=(X_val_s, y_val),
                    epochs=50, batch_size=256, callbacks=[early], verbose=0)
Backpropagation by hand for ONE sigmoid neuron with squared-error loss
import numpy as np

def sigmoid(z): return 1 / (1 + np.exp(-z))

x, y_true = 1.5, 1.0
w, b, lr = 0.2, 0.0, 0.5

for step in range(5):
    z = w * x + b
    y_hat = sigmoid(z)                                  # forward pass
    loss = 0.5 * (y_hat - y_true) ** 2
    # chain rule: dL/dw = dL/dy_hat * dy_hat/dz * dz/dw
    dz = (y_hat - y_true) * y_hat * (1 - y_hat)
    dw, db = dz * x, dz
    w, b = w - lr * dw, b - lr * db                     # gradient-descent update
    print(step, round(loss, 4))                         # loss shrinks each step

5. Convolutional Neural Networks (CNN): Spatial Feature Learning

What & Why

A CNN is built for grid-like data such as images. Instead of connecting every pixel to every neuron, it slides small learnable filters (kernels) across the image to detect local patterns (edges, then shapes, then objects). Key ideas: convolution layers (feature maps), pooling (down-sample, e.g. max pooling, to gain some translation tolerance), and a final dense classifier. Sharing filter weights across the image makes CNNs far more efficient than MLPs on pixels.

AnalogyScanning a document with a small magnifying glass, noting "there is a line here, a circle there", then combining those clues into "this looks like a passport photo page".
Finance example

Classifying scanned KYC document images (passport, Emirates ID, trade licence, ...) so they route to the right review queue automatically.

A small CNN in Keras for 64x64 document images
from tensorflow import keras
from tensorflow.keras import layers

# Adjust input_shape to your array: (64, 64, 1) for grayscale or (64, 64, 3) for colour.
num_classes = 5            # set from your label set

cnn = keras.Sequential([
    layers.Input(shape=(64, 64, 1)),
    layers.Rescaling(1.0 / 255),                       # pixel values 0-255 -> 0-1
    layers.Conv2D(16, 3, activation="relu"),
    layers.MaxPooling2D(),
    layers.Conv2D(32, 3, activation="relu"),
    layers.MaxPooling2D(),
    layers.GlobalAveragePooling2D(),
    layers.Dense(32, activation="relu"),
    layers.Dense(num_classes, activation="softmax"),
])
cnn.compile(optimizer="adam", loss="sparse_categorical_crossentropy", metrics=["accuracy"])
cnn.summary()

6. Recurrent Networks (RNN) and LSTM for Sequences

What & Why

An RNN processes a sequence one step at a time, carrying a hidden state that acts as memory of what it has seen so far, so order matters. Use it for ordered data: time series, text, event streams.

Plain RNNs struggle with long sequences because of the vanishing gradient problem (learning signals shrink as they flow back through many steps). LSTM (Long Short-Term Memory) units add a memory cell controlled by gates (forget, input, output) that decide what to keep, add and expose, which helps them learn longer dependencies. Input shape for sequence layers is (timesteps, features).

AnalogyReading a sentence word by word while keeping a mental summary; an LSTM is a reader with a notepad who can decide what to cross out and what to underline.
Finance example

Using the last 14 days of an ATM's withdrawals, holidays and payday flags to predict tomorrow's cash demand, or the last N card transactions of a customer to flag an unusual sequence.

Windowing a series and an LSTM forecaster
import numpy as np
from tensorflow import keras
from tensorflow.keras import layers

def make_windows(arr, window=14):
    # arr: 2D array (time, features), column 0 is the target. Returns X (n, window, f), y (n,)
    X, y = [], []
    for i in range(window, len(arr)):
        X.append(arr[i - window:i])          # the past `window` steps
        y.append(arr[i, 0])                  # the next value to predict
    return np.array(X), np.array(y)

# X_seq, y_seq = make_windows(scaled_series, window=14)

lstm = keras.Sequential([
    layers.Input(shape=(14, 5)),             # (timesteps, features)
    layers.LSTM(32),
    layers.Dense(1),
])
lstm.compile(optimizer="adam", loss="mse")

Common Pitfalls & Anti-Patterns

⚠ Skipping feature scaling for SVM and neural networks

Both are scale-sensitive; unscaled AED amounts can dominate the model and slow or break training.

⚠ Running a kernel SVM on millions of rows

Training time grows quickly with rows. Sample, use a linear model, or choose a tree ensemble.

⚠ Deep learning on a small tabular table

A forest or logistic model is usually as accurate, cheaper and easier to explain to a regulator.

⚠ Training for a fixed number of epochs with no validation

You cannot see overfitting. Monitor validation loss and use early stopping.

⚠ Random splits for sequence models

Windows from the future leak into training. Split chronologically before windowing.

⚠ Treating a network's output as a calibrated probability

Check calibration before using scores for pricing or limits.

Interactive Knowledge Check

Answer in your head (or out loud with a colleague) first, then reveal.

1. What are support vectors?

The training points closest to the decision boundary (on or inside the margin). They alone define the hyperplane.

2. A kernel SVM fits the training data perfectly but fails on validation. Which direction should C and gamma move?

Decrease C and/or decrease gamma for a smoother, more regularised boundary.

3. Why can't a deep network of linear layers (no activation) learn non-linear patterns?

Stacked linear transformations collapse into a single linear transformation; activations supply the non-linearity.

4. Name the four steps of one training iteration of a neural network.

Forward propagation, loss computation, backpropagation (gradients) and a weight update by the optimiser.

5. Which architecture for (a) scanned ID images, (b) 14 days of ATM history?

(a) CNN, (b) RNN/LSTM (or lag features with a tree or linear model).
