Training, regression & forecasting

12 scenario questions in the CertNexus style. Answer first, then open the explanation. Use as the end-of-day team quiz or for revision.

1You tune alpha on the test set and report the test score. The reported score is…

  • A. Unbiased
  • B. Optimistically biased
  • C. Pessimistically biased
  • D. Identical to CV
Show answer

B — The test set was used for a decision → it is no longer an independent estimate.

2Training error is low and validation error is high. The model is…

  • A. Under-fitting
  • B. Over-fitting
  • C. Well calibrated
  • D. Converging slowly
Show answer

B — High variance: memorises training data. Remedies: regularise, simplify, more data.

3Which regulariser can set coefficients exactly to zero?

  • A. Ridge (L2)
  • B. Lasso (L1)
  • C. Dropout
  • D. Early stopping
Show answer

B — L1 produces sparse solutions → built-in feature selection.

4Which CV scheme is appropriate for daily ATM withdrawals?

  • A. Shuffled k-fold
  • B. Stratified k-fold
  • C. TimeSeriesSplit / walk-forward
  • D. Leave-one-out
Show answer

C — Shuffling lets the model see the future; time-ordered splits avoid that.

5Gradient descent loss explodes after a few iterations. The most likely cause…

  • A. Learning rate too small
  • B. Learning rate too large
  • C. Too many epochs
  • D. Too few features
Show answer

B — Steps overshoot the minimum and diverge.

6Random search often matches grid search at a fraction of the cost because…

  • A. It uses GPUs
  • B. Only a few hyperparameters matter, and random sampling covers each one's range better
  • C. It skips cross-validation
  • D. It always finds the global optimum
Show answer

B — Bergstra & Bengio: random samples explore important dimensions more densely.

7Nested cross-validation is used to…

  • A. Speed up tuning
  • B. Estimate the performance of the whole tuning procedure without optimism
  • C. Tune two models at once
  • D. Handle missing values
Show answer

B — Inner loop tunes, outer loop evaluates on data the search never saw.

8R² = 0.97 but MAPE = 35% on property valuations. A likely explanation…

  • A. R² is dominated by large values; small properties have large relative errors
  • B. The model is perfect
  • C. MAPE is computed wrongly
  • D. Under-fitting
Show answer

A — R² is driven by high-value properties; MAPE weights every property equally.

9A lag-1 feature is unusable for a 7-day-ahead forecast because…

  • A. It is too noisy
  • B. It will not be known at forecast time
  • C. It is collinear
  • D. It violates stationarity
Show answer

B — The freshest usable lag is the forecast horizon.

10SARIMAX differs from ARIMA because it adds…

  • A. Neural layers
  • B. Seasonal terms and exogenous regressors
  • C. Tree ensembles
  • D. Classification output
Show answer

B — S = seasonal, X = exogenous drivers such as calendar effects.

11The cash team cares more about running out than about idle cash. Best forecast output?

  • A. Mean forecast
  • B. Upper-quantile (e.g. P90) forecast
  • C. Median only
  • D. R²
Show answer

B — Asymmetric costs → quantile forecasts.

12An income model is trained on customers with salary transfer and applied to those without. The main risk is…

  • A. Over-fitting
  • B. Selection bias / extrapolation to a different population
  • C. Class imbalance
  • D. Vanishing gradients
Show answer

B — The scored population differs systematically from the training population.
