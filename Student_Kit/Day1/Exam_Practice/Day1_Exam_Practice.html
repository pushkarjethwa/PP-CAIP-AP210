AI/ML foundations & data preparation

12 scenario questions in the CertNexus style. Answer first, then open the explanation. Use as the end-of-day team quiz or for revision.

1HGB wants to flag customers likely to close their account in the next 6 months, using last year's closures as examples. Which learning type?

  • A. Unsupervised clustering
  • B. Supervised classification
  • C. Reinforcement learning
  • D. Supervised regression
Show answer

B — There is a labelled binary outcome (closed / not closed) → supervised classification.

2Marketing asks for groups of customers with similar behaviour but has no labels. Most appropriate approach?

  • A. Logistic regression
  • B. k-means clustering
  • C. Linear regression
  • D. LSTM
Show answer

B — No target → unsupervised; k-means is the standard clustering choice.

3A loan feature months_in_arrears is recorded 12 months after disbursement. Using it to predict default at application time causes…

  • A. Under-fitting
  • B. Class imbalance
  • C. Data leakage
  • D. Multicollinearity
Show answer

C — The value is not known at decision time — classic target leakage.

4Salary is missing far more often for self-employed applicants. The missingness is best described as…

  • A. MCAR
  • B. MAR — related to an observed variable
  • C. Impossible to handle
  • D. A duplicate-record problem
Show answer

B — Missingness depends on an observed variable (employment type) → missing at random (MAR); add an indicator and impute.

5Which transformation is most appropriate for a heavily right-skewed balance variable before a linear model?

  • A. One-hot encoding
  • B. Log transform
  • C. Label encoding
  • D. Removing the column
Show answer

B — Log compresses the long right tail and makes multiplicative effects additive.

6Why must the imputer and scaler be fitted on the training split only?

  • A. It is faster
  • B. Fitting on all data leaks test-set information into training
  • C. Scikit-learn requires it
  • D. To reduce memory
Show answer

B — Statistics computed on test rows leak information → optimistic evaluation.

7A nominal feature emirate (7 values) for logistic regression should be…

  • A. Ordinal-encoded 1–7
  • B. One-hot encoded
  • C. Standardised
  • D. Dropped
Show answer

B — Ordinal codes impose a fake order on nominal categories; one-hot does not.

8After a left join, a customer without a card has no txn_count. The best fill is…

  • A. The median txn_count
  • B. 0, plus a has_card_activity indicator
  • C. Drop the customer
  • D. −1 for all features
Show answer

B — For counts, missing means zero; an indicator lets the model separate ‘no card’ from ‘inactive card’.

9In feature selection with a random ‘probe’ column, features scoring below the probe should be…

  • A. Kept — they might interact
  • B. Considered indistinguishable from noise and usually dropped
  • C. Scaled up
  • D. Used as the target
Show answer

B — The probe gives an empirical noise floor.

10Which is unstructured data?

  • A. A customer table
  • B. Scanned cheque images
  • C. A CSV of transactions
  • D. A parquet feature store
Show answer

B — Images, text and audio have no predefined columns.

11Standardisation (z-score) produces features with…

  • A. Range 0–1
  • B. Mean 0 and standard deviation 1
  • C. Only positive values
  • D. A normal distribution
Show answer

B — Min-max scaling gives 0–1; z-scoring gives mean 0, std 1 but does not change the distribution's shape.

12A vendor claims 99% AUC on credit default. The first thing to check is…

  • A. The GPU used
  • B. Leakage in features or splits
  • C. The number of trees
  • D. The colour of the ROC curve
Show answer

B — Implausibly high performance on a noisy banking target almost always means leakage.
