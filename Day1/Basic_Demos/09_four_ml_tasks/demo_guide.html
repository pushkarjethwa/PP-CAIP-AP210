Day 1 · Slide 9

Regression, classification, clustering, and forecasting

Starter codeComplete solution

From this demo’s folder, run the solution once, or use the numbered sections to show one idea at a time. The code under Setup runs first.

python solution.py
Setup code 
from sklearn.cluster import KMeans
from sklearn.linear_model import LinearRegression
from sklearn.tree import DecisionTreeClassifier

1. Regression

Say

Regression returns a number. This line learns the relationship from three pairs.

Look for

Input 4 gives the numeric prediction 9.0.

Run

reg = LinearRegression().fit([[1], [2], [3]], [3, 5, 7])
print("Numeric prediction:", round(reg.predict([[4]])[0], 1))

2. Classification

Say

Classification returns a class from a known set of labels. A binary model learns two classes. A multiclass model can learn three or more.

Look for

The binary model returns low and high. The three-class model returns middle for 4.

Run

clf = DecisionTreeClassifier(max_depth=1, random_state=0)
clf.fit([[0], [1], [8], [9]], ["low", "low", "high", "high"])
print("Predicted classes:", clf.predict([[2], [7]]).tolist())
three = DecisionTreeClassifier(max_depth=2, random_state=0)
three.fit([[0], [1], [4], [5], [8], [9]], ["low", "low", "middle", "middle", "high", "high"])
print("Three-class prediction:", three.predict([[4]])[0])

3. Clustering

Say

Clustering gets the same kind of inputs without the low and high labels. It discovers two groups from the distances.

Look for

0 and 1 are together, and 8 and 9 are together. Group IDs can be swapped.

Run

points = [[0], [1], [8], [9]]
clusters = KMeans(n_clusters=2, n_init=10, random_state=0).fit_predict(points)
print("Group IDs:", clusters.tolist())

4. Forecasting

Say

Here the input order represents time. Use earlier values to learn and keep the later value for checking.

Look for

The forecast for time 4 is 16, which matches the held-out observation.

Run

time_train = [[1], [2], [3]]
trend = LinearRegression().fit(time_train, [10, 12, 14])
print("Time 4 forecast:", round(trend.predict([[4]])[0], 1), "Actual:", 16)
