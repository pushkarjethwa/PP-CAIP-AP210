Day 1 · Slide 13

Base rate, conditional probability, lift, Bayes, and causation

Starter codeComplete solution

From this demo’s folder, run the solution once, or use the numbered sections to show one idea at a time. The code under Setup runs first.

python solution.py
Setup code 
import pandas as pd

table = pd.DataFrame({
    "X": [True, True, True, True, False, False, False, False],
    "Y": [True, True, True, False, True, False, False, False],
})

1. Base rate

Say

The base rate uses all eight rows. The mean of a Boolean column is its True fraction.

Look for

P(Y) is 4 out of 8, or 0.50.

Run

base = table["Y"].mean()
print("P(Y):", base)

2. Conditional probability and lift

Say

Keep the rows where X is true. The fraction of Y in these rows answers P(Y given X). Lift divides that fraction by the base rate.

Look for

P(Y given X) is 0.75 and lift is 1.5.

Run

y_given_x = table.loc[table["X"], "Y"].mean()
print("P(Y given X):", y_given_x, "Lift:", y_given_x / base)

3. Bayes' rule

Say

Reverse the condition using P(Y given X), P(X), and P(Y). Then check it by counting directly.

Look for

Both approaches return 0.75 for P(X given Y).

Run

bayes = y_given_x * table["X"].mean() / base
direct = table.loc[table["Y"], "X"].mean()
print("P(X given Y), Bayes:", bayes, "Direct count:", direct)

4. Correlation and cause

Say

I generated both columns from z. Their correlation is perfect because they share that input. Look at the expressions to see what controls b.

Look for

The correlation is 1.0. Reassigning a leaves b as [3, 6, 9, 12].

Run

z = pd.Series([1, 2, 3, 4])
a, b = 2 * z, 3 * z
print("Correlation:", round(a.corr(b), 2))
a = a + 10
print("b after changing a:", b.tolist())
