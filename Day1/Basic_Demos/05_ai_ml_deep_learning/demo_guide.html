Setup code 
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.neural_network import MLPClassifier

numbers = [1, 2, 3, 4]
x = [[1], [2], [3], [4]]
y = [3, 5, 7, 9]
bits = [[0, 0], [0, 1], [1, 0], [1, 1]]
different = [0, 1, 1, 0]

1. Written rule

Say

I supplied the rule. The computer applies it to each input.

Look for

The values at least 3 produce True.

Run

print([value >= 3 for value in numbers])

2. Learned rule

Say

Here I supply input-output examples. The model learns a line from them.

Look for

The predicted output for input 5 is 11.

Run

line = LinearRegression().fit(x, y)
print("Prediction for 5:", round(line.predict([[5]])[0], 2))

3. Neural network

Say

This small network has two hidden layers. It learns that only the pairs with different bits have label 1.

Look for

The model reproduces the four training labels. These are training predictions for illustration.

Run

net = MLPClassifier(hidden_layer_sizes=(8, 8), solver="lbfgs",
                    random_state=0, max_iter=1000).fit(bits, different)
print("Hidden layers:", net.hidden_layer_sizes)
print("Training predictions:", net.predict(bits).tolist())

4. Data science without a model

Say

Summarising values is already useful data work.

Look for

There are four values and their mean is 2.5.

Run

values = pd.Series(numbers)
print("Count:", values.count(), "Mean:", values.mean())
