Setup code 
import sys

import numpy as np
import pandas as pd
from scipy.signal import spectrogram
from sklearn.feature_extraction.text import CountVectorizer

texts = ["red red blue", "blue green"]
image = np.array([[0, 0, 255], [0, 255, 255]], dtype=np.uint8)
sample_rate = 1024

1. Structured tables

Say

Each table row is a record. Named columns have a consistent meaning and type.

Look for

There are two records, with a text column and an integer column.

Run

table = pd.DataFrame({"letter": ["a", "b"], "value": [3, 5]})
print(table)
print(table.dtypes)

2. Text tokens, counts, and embeddings

Say

Split into tokens and count each word. An embedding gives a token a short numeric vector. These tiny vectors are supplied to show their shape. Learned embeddings get their values from training.

Look for

Red appears twice in the first text. The embedding lookup represents its three tokens by a 3-by-2 array.

Run

tokens = texts[0].split()
counts = CountVectorizer()
matrix = counts.fit_transform(texts)
print("Tokens:", tokens)
print("Vocabulary:", counts.get_feature_names_out().tolist())
print("Word counts:\n", matrix.toarray())
embedding = {"red": [1.0, 0.0], "blue": [0.8, 0.2], "green": [0.1, 0.9]}
print("Lookup vectors:\n", np.array([embedding[token] for token in tokens]))

3. Image pixels and flattening

Say

A grayscale image is a grid of pixel intensities. Flattening gives a row of numbers. Keeping the grid preserves the row and column layout as separate axes.

Look for

The image has shape (2, 3). The flattened version has six intensity values.

Run

print("Image shape:", image.shape)
print("Flattened pixels:", image.ravel().tolist())

4. Audio samples and spectrogram

Say

Audio is a series of samples. A spectrogram tells us which frequencies are present in each short time window.

Look for

The synthetic wave has 128 samples. Its dominant spectrogram frequency is 128 Hz.

Run

seconds = np.arange(128) / sample_rate
wave = np.sin(2 * np.pi * 128 * seconds)
frequencies, times, power = spectrogram(wave, fs=sample_rate, nperseg=32, noverlap=16)
print("Audio samples:", wave.shape, "Spectrogram shape:", power.shape)
print("Dominant frequency:", frequencies[power.mean(axis=1).argmax()], "Hz")

5. Video frames and a visual check

Say

A video adds time to the pixel grid. Here it has just two frames.

Look for

Video shape is (2, 2, 3). With --plot, see the six grayscale pixels and the frequency band in the audio.

Run

video = np.stack([image, np.fliplr(image)])
print("Video shape (frames, rows, columns):", video.shape)

if "--plot" in sys.argv:
    import matplotlib.pyplot as plt

    fig, axes = plt.subplots(1, 2, figsize=(7, 3))
    axes[0].imshow(image, cmap="gray", interpolation="nearest", vmin=0, vmax=255)
    axes[0].set(title="Image pixels", xlabel="Column", ylabel="Row")
    axes[1].pcolormesh(times, frequencies, power, shading="auto")
    axes[1].set(title="Audio spectrogram", xlabel="Time (s)", ylabel="Frequency (Hz)")
    fig.tight_layout()
    plt.show()
