2. Vectorized maths vs a Python loop

The operation is doubling. The loop calls Python for each value. The array expression passes the job to NumPy.

The outputs match. The measured timings vary by machine and run.

Show step 2 code 
start = perf_counter()
doubled_loop = []
for value in big:
    doubled_loop.append(value * 2)
loop_seconds = perf_counter() - start
start = perf_counter()
doubled_array = big * 2
array_seconds = perf_counter() - start
print("Same values:", np.array_equal(doubled_loop, doubled_array))
print(f"Loop: {loop_seconds:.5f}s | Array: {array_seconds:.5f}s")

1. Base rate

The base rate uses all eight rows. The mean of a Boolean column is its True fraction.

Keep the rows where X is true. The fraction of Y in these rows answers P(Y given X). Lift divides that fraction by the base rate.

1. Target leakage

This feature is a copy of the label produced after the outcome. A model gets a perfect score because the answer is in the input.

The model with the copied outcome gets AUC 1.00. The available-only input gets 0.75.

Show step 1 code 
train["outcome_copy"] = train["label"]
test["outcome_copy"] = test["label"]
for names in [["input"], ["input", "outcome_copy"]]:
    model = DecisionTreeClassifier(max_depth=1, random_state=0).fit(train[names], train["label"])
    score = roc_auc_score(test["label"], model.predict_proba(test[names])[:, 1])
    print(names, "test AUC:", round(score, 2))

2. Train-test contamination

The mean belongs to the training set. Fitting a scaler after combining both sets lets the test set change that mean.

The training-only scaler learns mean 2.0. The contaminated scaler learns mean 13.2.

Show step 2 code 
train_values = [[1], [2], [3]]

contaminated = StandardScaler().fit(train_values + test_values)

3. Temporal leakage

When the model will predict future rows, test on later rows. A shuffled split can train on dates after the ones in the test set.

The shuffled training set includes time points after some test points. In the ordered split, the latest training point is 7 and the earliest test point is 8.
