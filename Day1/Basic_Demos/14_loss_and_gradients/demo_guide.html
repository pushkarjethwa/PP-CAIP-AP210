3. Binary cross-entropy

Say

For classification, cross-entropy penalises confident errors heavily. Here the input probabilities refer to class 1.

Look for

The better probabilities have loss about 0.105. The confident errors have loss about 2.303.

Run

print("Well matched:", round(log_loss([0, 1], [0.1, 0.9]), 3))
print("Confident errors:", round(log_loss([0, 1], [0.9, 0.1]), 3))

4. Gradient descent and learning rate

Say

At each step, subtract the gradient times the learning rate. Watch where the weight goes when I make the step too large.

Look for

Rate 0.25 moves toward weight 3 and loss 0. Rate 1.1 overshoots and the loss grows.

Run

paths = {}
for rate in [0.25, 1.1]:
    weight = 0.0
    weights = [weight]
    for _ in range(4):
        gradient = 2 * (weight - 3)
        weight -= rate * gradient
        weights.append(weight)
    paths[rate] = np.array(weights)
    print("Rate:", rate, "Weights:", paths[rate].round(2),
          "Losses:", ((paths[rate] - 3) ** 2).round(2))

5. Show the loss curve

Say

The bottom of the curve is the minimum. The dots show successive weights for the smaller step size.

Look for

With --plot, the points move down a U-shaped curve toward weight 3.

Run

if "--plot" in sys.argv:
    import matplotlib.pyplot as plt

    grid = np.linspace(-0.5, 6.5, 150)
    plt.plot(grid, (grid - 3) ** 2, label="Loss")
    plt.scatter(paths[0.25], (paths[0.25] - 3) ** 2, label="Descent steps")
    plt.xlabel("Weight")
    plt.ylabel("Loss")
    plt.legend()
    plt.tight_layout()
    plt.show()
