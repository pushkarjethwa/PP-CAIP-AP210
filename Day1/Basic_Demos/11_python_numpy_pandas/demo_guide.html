Setup code 
from time import perf_counter

import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

values = np.array([10, 20, 30])
big = np.arange(300_000)
table = pd.DataFrame({"id": [1, 2, 3, 4], "group": ["a", "a", "b", "b"],
                      "value": [2, 4, 6, 8]})
labels = pd.DataFrame({"group": ["a", "b"], "name": ["alpha", "beta"]})
train_x = [[1], [2], [3]]
train_y = [2, 4, 6]

1. Array, shape, dtype, and boolean mask

Say

Shape tells us the size of each axis. A comparison gives one True or False per value. The mask keeps only True entries.

Look for

The array has shape (3,), contains integers, and the mask selects 20 and 30.

Run

print("Shape:", values.shape, "dtype:", values.dtype)
mask = values >= 20
print("Mask:", mask.tolist(), "Selected:", values[mask].tolist())

2. Vectorized maths vs a Python loop

Say

The operation is doubling. The loop calls Python for each value. The array expression passes the job to NumPy.

Look for

The outputs match. The measured timings vary by machine and run.

Run

start = perf_counter()
doubled_loop = []
for value in big:
    doubled_loop.append(value * 2)
loop_seconds = perf_counter() - start
start = perf_counter()
doubled_array = big * 2
array_seconds = perf_counter() - start
print("Same values:", np.array_equal(doubled_loop, doubled_array))
print(f"Loop: {loop_seconds:.5f}s | Array: {array_seconds:.5f}s")

3. DataFrame, Series, dtypes, and apply

Say

A DataFrame is the table. Selecting one column gives a Series. apply calls the function for each value here.

Look for

The apply result matches the vectorized multiplication.

Run

column = table["value"]
print(type(table).__name__, type(column).__name__)
print(table.dtypes)
print("Same result:", column.apply(lambda x: x * 2).equals(column * 2))

4. Chaining and named aggregation

Say

assign adds a column to the returned table. groupby creates groups and agg names the summaries.

Look for

The summary counts rows and shows their means by group and by high value.

Run

summary = (table.assign(high=table["value"] > 4)
           .groupby(["group", "high"])
           .agg(count=("id", "size"), mean=("value", "mean")))
print(summary)

5. Merge tables

Say

The group column links the two tables. A left merge preserves the original rows.

Look for

Rows in group a get alpha and rows in group b get beta.

Run

print(table.merge(labels, on="group", how="left"))

6. Pure transformation

Say

A pure function takes an input and returns a result without changing the original table.

Look for

The new result has doubled. The original columns are unchanged.

Run

def add_doubled(frame):
    return frame.assign(doubled=frame["value"] * 2)

print(add_doubled(table))
print("Original columns:", table.columns.tolist())

7. fit, transform, predict, and Pipeline

Say

fit learns parameters. transform applies a learned conversion. predict returns model outputs. A Pipeline runs the steps in order.

Look for

The scaler learns mean 2. The fitted pipeline predicts 8 for input 4.

Run

scaler = StandardScaler().fit(train_x)
print("Learned mean:", scaler.mean_, "Scaled 4:", scaler.transform([[4]]))
pipe = Pipeline([("scale", StandardScaler()), ("model", LinearRegression())])
pipe.fit(train_x, train_y)
print("Prediction for 4:", pipe.predict([[4]]).round(2))
