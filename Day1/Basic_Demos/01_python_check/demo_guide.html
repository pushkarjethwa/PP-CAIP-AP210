Python and package check

Starter codeComplete solution

From this demo’s folder, run the solution once, or use the numbered sections to show one idea at a time. The code under Setup runs first.

python solution.py
Setup code 
import sys

import matplotlib
import numpy as np
import pandas as pd
import pyarrow
import scipy
import sklearn

1. Check Python

Say

Run this in the same terminal you'll use for the demos.

Look for

The terminal prints the Python version and interpreter path.

Run

print("Python", sys.version.split()[0])
print("Interpreter", sys.executable)

2. Check the imports

Say

A successful import confirms this interpreter can see the package.

Look for

A version prints for each package, including PyArrow for the Parquet example.

Run

print("numpy", np.__version__)
print("pandas", pd.__version__)
print("pyarrow", pyarrow.__version__)
print("scipy", scipy.__version__)
print("scikit-learn", sklearn.__version__)
print("matplotlib", matplotlib.__version__)
