Setup code 
from sklearn.metrics import confusion_matrix
from sklearn.tree import DecisionTreeClassifier

values = [2, 4, 6]
labels_by_code = {"A": "alpha", "B": "beta"}
x_train = [[0, 0], [0, 1], [1, 0], [1, 1], [2, 0], [2, 1]]
y_train = [0, 0, 1, 1, 1, 1]
x_check = [[0, 0], [1, 1], [2, 1]]
y_check = [0, 1, 0]

1. Fixed rule and lookup

Say

The threshold and lookup both give exact answers from definitions we've supplied.

Look for

The threshold returns False, False, True. The lookup returns beta.

Run

print("Above 4:", [value > 4 for value in values])
print("Code B:", labels_by_code["B"])

2. Learn and check mistakes

Say

A model learns from examples. Look at its mistakes on separate rows and ask whether the examples cover what will come next.

Look for

One check row has a false positive. The confusion matrix puts actual labels on rows and predicted labels on columns.

Run

model = DecisionTreeClassifier(max_depth=1, random_state=0).fit(x_train, y_train)
predicted = model.predict(x_check)
print("Predicted:", predicted.tolist(), "Actual:", y_check)
print("Confusion matrix:\n", confusion_matrix(y_check, predicted, labels=[0, 1]))
