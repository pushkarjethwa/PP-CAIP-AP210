1. Supervised

Run

2. Unsupervised clustering

Say

We only supply the positions. The model groups points by proximity.

Look for

The first three points share one group and the final three share another. The ID numbers are arbitrary.

Run

groups = KMeans(n_clusters=2, n_init=10, random_state=0).fit_predict(x)
print("Group IDs:", groups.tolist())

3. Unsupervised dimension reduction

Say

PCA finds a direction that preserves as much variation as possible in fewer columns.

Look for

Three rows with two columns become three rows with one component.

Run

component = PCA(n_components=1).fit_transform([[1, 2], [2, 4], [3, 6]])
print("Reduced shape:", component.shape)

4. Unsupervised anomaly detection

Say

An isolation forest flags values that are easier to separate from the rest.

Look for

The final value, 20, is flagged with -1.

Run

points = [[1], [1.1], [1.2], [1.3], [20]]
flags = IsolationForest(contamination=0.2, random_state=0).fit_predict(points)
print("Anomaly flags:", flags.tolist(), "(-1 means unusual)")

5. Reinforcement learning

Say

This one-state example learns the value of each action from rewards. The simplest policy picks the action with the larger estimated value.

Look for

The running estimates favour action B after four practice actions.

Run

q = {"A": 0.0, "B": 0.0}
for action, reward in [("A", 1), ("B", 3), ("A", 1), ("B", 3)]:
    q[action] += 0.5 * (reward - q[action])
print("Action values:", q, "Chosen action:", max(q, key=q.get))

6. Semi-supervised

Say

A model receives a few labelled points and uses their proximity to help assign labels to the remaining points.

Look for

The model spreads label 0 around the first point and label 1 around the final point.

Run

partly_labelled = [0, -1, -1, -1, -1, 1]
spread = LabelSpreading().fit(x, partly_labelled)
print("Inferred labels:", spread.transduction_.tolist())

7. Self-supervised

Say

We make the targets from the data itself. In a next-token task, each following token becomes the answer for the preceding token.

Look for

The generated examples show B most often follows A.

Run

tokens = "A B A B A C".split()
pairs = list(zip(tokens, tokens[1:]))
after_a = Counter(target for source, target in pairs if source == "A")
print("Generated pairs:", pairs)
print("Most likely next token after A:", after_a.most_common(1)[0][0])
