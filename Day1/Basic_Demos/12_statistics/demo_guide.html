Centre, spread, skew, and four distributions

Starter codeComplete solution

From this demo’s folder, run the solution once, or use the numbered sections to show one idea at a time. The code under Setup runs first.

python solution.py
python solution.py --plot
Setup code 
import sys

import numpy as np
import pandas as pd

values = pd.Series([1, 2, 2, 3, 12])
rng = np.random.default_rng(42)

1. Mean and median

Say

The mean uses every magnitude. The median sits at the middle of the sorted values.

Look for

The mean is 4.0 and the median is 2.0.

Run

print("Mean:", values.mean(), "Median:", values.median())

2. Variance and standard deviation

Say

Both describe spread. Standard deviation is the square root of variance and is in the same units as the values.

Look for

Using sample formulas, variance is 20.5 and standard deviation is about 4.53.

Run

print("Sample variance:", round(values.var(), 2))
print("Sample standard deviation:", round(values.std(), 2))

3. Skew and a log

Say

The large value makes a right tail. A log compresses the higher values more than the lower ones.

Look for

The skew is positive and decreases after the log.

Run

print("Skew before log:", round(values.skew(), 2))
print("Skew after log:", round(np.log(values).skew(), 2))

4. Normal, log-normal, binomial, and Poisson

Say

The normal is symmetric. The log-normal is positive and often right-skewed. A binomial counts successes in a fixed number of tries, and a Poisson counts events in an interval.

Look for

With --plot, the first two panels show continuous values and the last two show integer counts. Binomial values stay between 0 and 10.

Run

samples = {
    "Normal": rng.normal(0, 1, 500),
    "Log-normal": rng.lognormal(0, 1, 500),
    "Binomial": rng.binomial(10, 0.3, 500),
    "Poisson": rng.poisson(3, 500),
}
for name, sample in samples.items():
    print(name, "mean =", round(sample.mean(), 2),
          "range =", np.round([sample.min(), sample.max()], 2))

if "--plot" in sys.argv:
    import matplotlib.pyplot as plt

    fig, axes = plt.subplots(2, 2, figsize=(7, 5))
    for ax, (name, sample) in zip(axes.flat, samples.items()):
        bins = np.arange(sample.max() + 2) - 0.5 if sample.dtype.kind == "i" else 24
        ax.hist(sample, bins=bins)
        ax.set(title=name, xlabel="Value", ylabel="Frequency")
    fig.tight_layout()
    plt.show()
